# 个人书房 1.0.0 · Windows x64

将整个压缩包解压到有写入权限的目录，例如 D:\Apps\NovelReader。保留 client、server 和其中的文件。

## 首次打开

1. 双击 server\NovelServer.exe，等待控制台显示监听地址，并在阅读期间保持服务运行。
2. 双击 client\novel_reader.exe。两端位于同一份解压目录时，阅读器会从相邻服务端目录读取首次启动生成的个人令牌。
3. 在“搜书”输入“绝世剑神”，打开搜索结果，点击“加入书架”或“继续阅读”。初次建库带有两个经过在线验证的普通书源。也可在“书源 → 导入书源”中粘贴 Legado JSON、合集 URL 或选择 JSON 文件。
4. 在“书架 → 导入电子书”选择 TXT 或 EPUB。TXT 可预览编码；上传解析完成后，其他设备连接同一服务即可看到该书。

## 阅读操作

- “继续阅读”打开上次读到的位置。点击正文中间显示或收起菜单，右上角可调整字号、行距、滚动／分页和夜间模式。Windows 支持鼠标滚轮、方向键和 PageUp／PageDown。
- 阅读位置会延迟约半秒保存，并在切章和使用阅读器返回按钮时提交。重读前面的章节也会更新进度。离线可重读最近 30 章，包括 EPUB 插图。
- “历史”按最近阅读时间列出书籍，移出书架后仍可继续阅读。“删除服务器原书”会一并删除服务器上的文件、目录、历史和进度。
- 离线期间另一设备也读过同一本书时，下次打开该书会显示两处位置，选择保留本机或服务端进度。

## 使用自己的服务器

“连接”中填写完整服务地址和个人令牌。本机默认地址为 http://127.0.0.1:7186。服务端首次运行会生成 server\data\access-token.txt。其他设备使用服务器实际可达的地址。公网部署时在 HTTPS 反向代理后运行。

服务启动前可设置环境变量：

| 变量 | 作用 |
|---|---|
| ASPNETCORE_URLS | 监听地址。局域网示例为 http://0.0.0.0:7186，需要时为该端口配置防火墙。 |
| NOVEL_DATA | 服务器数据目录。默认是服务端 EXE 旁的 data。 |
| NOVEL_TOKEN | 指定个人令牌。使用此项时，在客户端“连接”中填写同一令牌。 |
| NOVEL_PROFILE | 指定独立的客户端配置与章节缓存目录，用于在同一台电脑模拟另一台设备。 |

备份时先退出服务端，再复制完整的数据目录。恢复时关闭服务端，将目录还原至原位置或用 NOVEL_DATA 指向它。上传原书位于 originals 子目录，阅读数据库为 library.sqlite。升级程序前保留整份数据目录。

## 本版范围

首版支持常用声明式文本书源和无 DRM 的重排 EPUB。导入有脚本依赖的书源时，管理页显示具体规则提示。真实网站会变化，可用“测试书源”重测。番茄入口显示暂不可用。本次发布包仅包含 Windows x64 客户端和自包含服务端。
