# 个人书房 2.0.1 · Windows x64

书架、搜索和详情页会优先显示书源或 EPUB 提供的封面。原有书籍首次显示时也会补取封面。下载成功后可离线查看；TXT 及缺少原封面的书使用山水插画和书名。
解压整个目录，双击 **Start-Reader.cmd**。它分别启动 .NET 服务和 Flutter 阅读器，默认只监听本机 7187，首版可以继续占用 7186。请保留 client 里的 DLL 和 data。在资源管理器手动启动 server/NovelServer.exe 时，默认使用 7186；手动打开 client/novel_reader.exe，可从「我的 → 连接与同步」设置服务地址及令牌。

**导入首版书库**：先关闭首版客户端，再正常退出首版服务端；备份整个首版 server/data（包括 originals、SQLite 文件及如有的 -wal/-shm、access-token.txt）。在二版第一次启动前把这份完整副本放入二版 server/data。二版启动时升级副本。不要让两个版本共同写一个目录。如果二版已经建立了书库，请先退出二版、完整备份二版目录再操作；直接替换不是两库合并。启动脚本使用独立 profile；迁移之后若连接失效，请在「我的 → 连接与同步」重新输入二版 server/data/access-token.txt 中的值。书架、历史、进度属于服务端；阅读外观、缓存、尚未上传的进度属于设备。手动启动沿用原客户端的系统配置目录，请先在首版完成进度同步。不要公开分发生成的令牌、profile 或 data。

**阅读**：书架顶部搜索；右上角菜单上传 TXT、EPUB、建组、切换布局。点击封面打开正文；长按或右键管理书籍。默认连续滚动，左右各点一下也可翻一屏；屏幕中间呼出底栏，设置可选分页动画和文字样式。「菜单」页自定义九宫格和底栏；「信息」页调整页眉、页脚。按方向键或 PageUp/PageDown 翻页。按下鼠标右键或长按文字，可选择字符、高亮、下划线、批注、复制和修正；目录面板可切换到书签批注。点击插图可放大。无法联网时可重读本机保留的最近 30 章；书签批注等写入需要连接，阅读进度会在恢复联网后补传。

**多设备**：在可信局域网中单独启动服务端，设置 ASPNETCORE_URLS=http://0.0.0.0:7187 和 NOVEL_DATA 为同一份二版书库的绝对路径。不要同时在同一数据目录启动另一份服务。客户端连接 http://服务器局域网IP:7187 并填写个人令牌。关闭服务前先退出正在使用的阅读器。服务进程为 NovelServer.exe；一键启动使用隐藏窗口，需要退出时可按任务管理器显示的安装路径辨认。

番茄仍标为暂不可用。书源段评依赖源站提供的标记、文字或链接；不会生成虚构评论，也不执行书源脚本。简繁转换是离线逐字转换，异体字和需要上下文的词语可能不符合原意。本包只含 Windows x64 可执行文件。
