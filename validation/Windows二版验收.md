# Windows 阅读器 2.0 · 验收记录

版本：2026-11-14。参考 [Legado MD3 固定提交](https://github.com/HapeLee/legado-with-MD3/tree/4efe24965915a326f5e910197cb73966892f2eb0)。[原版与新版界面对照](v2-comparison.html)：书架、底部菜单、设置、窄窗及宽窗。右侧截图来自 Windows 原生 Flutter 引擎，使用测试书库。

重新运行 Windows 集成测试时，使用 `pwsh -File ./validation/v2-integration.ps1` 验证本地导入与同步。加上 `-Online` 会为测试书库导入样例书源，并运行在线搜书用例。

| 场景 | 结果与证据 |
|---|---|
| 三个点击区、分页跨章与连续滚动 | 默认左退、右进、中间显示工具栏；两向越过章界，从当前章第一页返回上一章末页；往返各 20 次、取消短拖动、打开设置切换滚动、锚点重排，以及文字替换后的 UTF-16 位置映射均在 [Flutter 回归](v2-flutter.log) 中通过。 |
| 本地导入、书架、离线、冲突 | [Windows 原生测试](v2-native.log) 使用独立文件选取测试适配器触发上传，真实 HTTP、SQLite、两个独立客户端目录。GB18030 TXT、三章带插图 EPUB，字号不同读取同一进度、断网重启、离线补传、冲突选择、主动回读与 30 章缓存淘汰通过。没有把程序化文件选取记作系统选取器手工测试。 |
| 真实普通书源 | [本轮结果](v2-online-results.json)：古龙武侠样本 60 章目录，前三章 6604 / 10212 / 6192 字符；疯读《绝世剑神》6003 章目录，前三章 3476 / 3125 / 1880 字符；每站三章的正文哈希均不相同。《绝世剑神》另在原生 UI 运行从指定源搜索、加入书架、第一章到第三章、回第二章。其余源没有逐一实读认证。 |
| 数据升级 | [12 项 API 检查](v2-api-results.json)：从首版 QA 数据库做 SQLite 在线备份。升级前后逐行比对 24 本书、6039 章、2 条进度、20 条历史、2 个书源、1 个插图资源；另测分组、书签批注、词典、规则、换源映射、全书搜索和 TXT 重分章。 |
| 最终发布程序 | [发布版启动记录](v2-smoke.json)：独立服务端启动，读取三章 EPUB，在 A、B、A 三次启动打包的客户端并检查窗口响应、客户端真实读到远端书架、书架打开未改写进度。UI 逐步点击阅读的记录来自同一源码的 Windows 原生集成测试。ZIP 已校验全部条目 CRC、必需动态库和资源，没有服务数据或令牌。 |

**验证范围**：仅 Windows x64 发布和联调。Android 和 macOS 保留 Flutter 工程，未在设备上验收；Android 音量键、电量信息均需真机复核。三种卷页使用不同曲面参数，不承诺与 Android 原生动画逐帧一致。设置支持九种模式；当前回归重点是切换后的锚点和跨章行为。段评读取来自书源明确提供的计数、文字和链接；只提供计数的源不显示虚构评论，脚本型段评不执行。两个实读样本未验证到在线段评正文。在线词典需要用户提供可用地址和释义规则。番茄仍暂不可用，见[逐步验证记录](番茄验证.md)。本次不交付听书、AI 或在线翻译。
