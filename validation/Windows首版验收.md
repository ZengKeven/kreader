# 个人书房 1.0.0 · Windows 首版验收

2026-11-14。Windows x64，Flutter 3.47.7、Dart 3.13.5、.NET SDK 10.0.401。Windows Release 使用自包含 .NET 服务端、Flutter AOT 及随包 VC++ 运行库。

| 验收项 | 结果 |
|---|---|
| 书源合集 | 快照 267 项全部导入，按必经字段诊断 107 项可尝试执行，160 项标有脚本、缺失规则等原因。逐项结果见 source-diagnostics.json。107 项是静态候选数量。 |
| 真实站点 | 古龙武侠定位到《绝代双骄》的小说目录并打开“名剑香花”和“刀下遗孤”；疯读小说打开《绝世剑神》前两章。检索结果、日期、两章长度及摘要哈希见 online-results.json。两个实测源随服务端首次建库导入。 |
| 服务端 | local.ps1 对发布 EXE 完成 14 项验收，包含 GB18030 TXT、带插图 EPUB、章内目录锚点、原书去重、鉴权、版本冲突、幂等、重启和删除。详见 local-results.json。 |
| Flutter 阅读定位 | 窗口宽度和字号变化下的文字锚点测试通过。Dart analyze 无问题。 |
| Windows 原生集成 | 两个 Flutter integration_test 测试通过。本地链路使用真实服务、真实文件和两个独立客户端数据目录，通过导入按钮选择样本，验证插图、窄窗分页、断网重读、重连冲突、主动回读和 30 章缓存。在线链路通过搜书界面检索《绝世剑神》，加入书架、阅读并切换到第二章。 |
| 独立发布目录 | 正式服务端与正式客户端直接运行，独立配置 A、B、A 三次启动均进入响应正常的窗口，并通过接口取得同一本已上传电子书；详见 release-smoke.json。 |
| 验证边界 | 集成测试为文件选择器注入样本路径，断网用抛出连接异常的传输层模拟。独立发布 EXE 的窗口控件未逐项人工点击；桌面截图访问超时。Android、macOS 未构建或实机运行。番茄通道单独见番茄验证.md。 |
